# Take demo identity

Take is a fictional essentials label created for this storefront template. All products, reviews and brand narrative are demonstration content.

## Identity

The geometric T monogram is an original code-native SVG, supplied as `public/brand/take-mark.svg`. The header, footer, mobile menu, favicon and social card use the same mark. The wordmark uses the existing sans-serif typeface.

## Product visuals

Nine original product images were generated with the built-in `image_gen` tool, then exported as WebP to `public/images/take`. No source brand photographs were used as references. These assets replace the previous nine photographs throughout the catalog and all pages consuming it. The previous photos were removed from the distributed public directory.

Exact prompts are recorded in [take-assets.json](take-assets.json): substitute each asset's `subject` for `[SUBJECT]` in `commonPrompt`. The requested background was opaque white.

The `california-long-sleeve` product URL is retained for existing links; its display name is now Take Studio Long Sleeve.

This fictional identity is demo content, not a trademark search or a guarantee of approval by any hosting or security service.
